# Security Policy

## Supported Versions

Currently, we provide security updates for the following versions of CrewFlow:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for us. If you discover a security vulnerability within CrewFlow, please send an e-mail to the repository owner rather than creating a public issue.

We will review all security reports and will do our best to address them in a timely manner. Please provide as much information as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We appreciate your effort and responsible disclosure!
