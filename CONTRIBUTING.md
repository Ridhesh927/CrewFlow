# Contributing to CrewFlow

First off, thank you for considering contributing to CrewFlow! It's people like you that make CrewFlow such a great tool.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) page to see if someone else has already created a ticket. If not, go ahead and make one!

## 2. Fork & create a branch

If this is something you think you can fix, then fork CrewFlow and create a branch with a descriptive name.

```bash
git checkout -b fix/your-bug-fix-name
```

## 3. Get the test suite running

Make sure your environment is properly set up according to the Setup Instructions in the `README.md`. Run any linters or tests to ensure your changes are clean.
```bash
cd frontend
npm run lint
```

## 4. Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## 5. Make a Pull Request

Once you are satisfied with your changes, create a Pull Request. Please make sure to fill out the PR template properly. We will review your PR and merge it once approved.
